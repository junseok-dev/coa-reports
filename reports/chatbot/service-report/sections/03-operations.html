03

관리자 운영 범위

세부 사용법과 현재 수치는 관리자 화면에서 직접 확인합니다. 여기서는 운영자가 스스로 처리할 수 있는 일과 시스템 작업이 필요한 일을 구분합니다.

운영

상담 운영 대시보드, 개선 검토와 비용 관리에서 이용 흐름·미확인 문제·AWS 및 OpenAI 비용을 확인합니다.

콘텐츠

문서 검토, FAQ와 프롬프트에서 답변 근거와 상담 원칙을 변경하고 버전·승인·복구 이력을 관리합니다.

관리 도구

대화·처리·감사 로그, 데이터 콘솔, 보안 정보, 모델·암호화 설정과 관리자 권한을 목적에 맞게 사용합니다.

운영자가 관리자 화면에서 처리할 수 있는 일

  • 문서 업로드·변환 검토·승인·반려·복구와 필요한 경우 FAISS 재구성
  • FAQ 추가·수정·삭제와 프롬프트 버전 관리·복구
  • 오류·문맥 불일치·답변 불만·반복 실패·안전 처리 실패 검토와 완료 처리
  • 대화 로그 조회, 상담 세션 상세 확인, Excel 내보내기와 관리자 활동 추적
  • n·Xavis 월별 비용 파일 및 OpenAI Usage 월 비용 입력·수정·삭제
  • 허용된 운영 환경설정과 접속 정보 등록·수정·삭제, 답변·임베딩 모델 변경
  • 관리자 계정 추가·삭제와 최상위 관리자 변경

이관 후 첫 접속: 관리 도구 → 보안 정보에서 승인된 보안 채널로 전달받은 임시 보관 비밀번호를 입력해 잠금을 해제한 뒤, 즉시 비밀번호 재설정에서 새 운영 비밀번호로 변경합니다. 실제 임시 비밀번호는 공개 보고서에 기록하지 않습니다. 신규 DB는 최상위 관리자가 8자 이상이며 특수문자를 포함한 비밀번호를 최초 설정합니다.

개발 또는 시스템 작업이 필요한 일

관리자 화면 밖의 변경
변경이유필요 작업
화면·통계·판단 로직애플리케이션 소스에 구현된 동작입니다.코드 수정, 테스트, 커밋·푸시와 배포가 필요합니다.
DB·S3·EC2·네트워크서비스가 기동되기 전부터 필요한 인프라입니다.AWS 권한, 백업, 보안그룹, 서비스와 DNS 설정이 필요합니다.
ENCRYPTION_KEY·JWT_SECRET보안 정보와 관리자 세션을 보호하는 루트 설정입니다.관리자 화면에서 변경하지 않고 배포 환경에서 통제합니다.
Google OAuth 프런트 설정VITE_GOOGLE_CLIENT_ID는 빌드할 때 프런트 코드에 반영됩니다.Secret 변경 후 프런트 재빌드·배포와 Authorized origin 검증이 필요합니다.
도메인 변경CORS, OAuth origin, DNS·HTTPS와 외부 진입 링크가 함께 영향을 받습니다.코드·Google Cloud·DNS·인증서·홈페이지 연결을 한 번에 점검합니다.

운영 판단: 콘텐츠와 일상 운영은 관리자 화면이 기준입니다. 반면 서비스가 시작되기 전 필요한 연결정보, 보호 키, 인프라와 배포는 관리자 화면만으로 해결할 수 없으므로 별도의 환경 구성 절차가 필요합니다.
