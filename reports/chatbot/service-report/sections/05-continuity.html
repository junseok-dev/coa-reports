필수 구성 기준

운영 환경별 준비 항목과 완료 조건
영역필수 작업완료 조건
저장소 회사 조직에 private repository를 만들고 소스, 환경변수 예시, 마이그레이션과 배포 워크플로를 등록합니다. main 브랜치에 실제 비밀값 없이 전체 실행 소스가 존재합니다.
운영 계정 AWS, OpenAI, Google Cloud와 채널톡을 회사 소유 계정으로 구성하고 비상 관리자와 MFA를 설정합니다. 결제, 보안 알림과 복구 권한의 주체가 회사 계정입니다.
인프라 EC2, RDS, S3, DNS·HTTPS를 구성하고 필요한 경우 승인된 방식으로 운영 데이터를 이전합니다. API·DB·S3·도메인 연결과 백업 정책이 정상입니다.
배포 GitHub Actions Secrets, self-hosted runner, systemd 서비스, 작업 경로와 EC2 instance ID를 설정합니다. main push로 배포되고 서비스가 정상 재시작됩니다.
관리자 설정 Google 관리자 로그인 후 보안 정보 비밀번호, 콘텐츠, 모델과 관리자 계정을 설정합니다. 사용자 채팅, 관리자 기능, 상담 연결과 로그 저장이 정상입니다.

운영 데이터 적용 기준

신규 환경

새 데이터베이스로 시작

새 RDS와 S3를 사용하고 ENCRYPTION_KEY·JWT_SECRET을 새로 생성합니다. 기존 대화와 로그는 포함하지 않습니다.

데이터 유지

승인된 운영 데이터 이전

RDS snapshot과 S3 객체를 함께 이전합니다. 암호화된 데이터를 유지하려면 기존 ENCRYPTION_KEY를 보안 자산으로 이전하거나 사전에 새 키로 재암호화합니다.

최종 운영 검증

  • GitHub Actions 배포와 EC2 서비스 재시작
  • API, DB 읽기·쓰기, S3와 EC2 상태 확인
  • Google 관리자 로그인과 관리자 권한 확인
  • 보안 정보 비밀번호 재설정과 자동 잠금 확인
  • FAQ·문서 기반 답변과 상담 연결 버튼 확인
  • 문서 승인, FAISS 재구성과 S3 동기화 확인
  • 대화·처리·감사 로그와 Excel 내보내기 확인
  • OpenAI Usage와 비용 관리 입력·수정·삭제 확인
  • RDS·S3 백업과 Secret 원본 보관 위치 기록

완료 기준: 회사 소유 계정만으로 배포, 로그인, 문서 반영, 상담 연결, 로그 확인과 복구를 수행할 수 있습니다.
